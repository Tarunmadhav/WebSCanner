# WebSCanner

WebSCanner is a personal Python-based passive web security scanner.

## Features

- HTTP/HTTPS target validation
- Same-origin crawling
- Security header checks
- Cookie checks
- Basic information disclosure checks
- JSON reports
- HTML reports

## Usage

python -m webscanner https://example.com

## Authorization

Only scan websites and applications that you own or have explicit permission to test.
